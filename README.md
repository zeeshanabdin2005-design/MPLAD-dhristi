
# 🇮🇳 MPLADS-DRISHTI

### AI-Powered Anomaly, Fraud & Compliance Intelligence System for MPLADS

> **SEE THE SIGNAL. VERIFY THE EVIDENCE. ACT WITH CONFIDENCE.**

MPLADS-DRISHTI is an AI-powered monitoring and investigation platform designed to help authorities identify anomalies, potential fraud indicators, project inefficiencies, and compliance issues in the implementation of the **Members of Parliament Local Area Development Scheme (MPLADS)**.

Instead of relying entirely on manual monitoring, DRISHTI brings together financial data, project progress, documents, images, GIS information, contractor activity, and historical records to generate explainable risk signals and prioritize projects that require human verification.

---

## 🎯 Problem Statement

### Smart India Hackathon 2026 — Problem Statement ID: 26102

**Development of an AI-powered system to detect anomalies, fraud, and inefficiencies in MPLAD Scheme implementation.**

MPLADS involves a large number of development works distributed across different locations. Monitoring these projects manually can make it difficult to identify unusual financial patterns, delays, inconsistencies, duplicate works, and other potential issues at an early stage.

MPLADS-DRISHTI addresses this challenge by creating a centralized intelligence layer for project monitoring and investigation.
